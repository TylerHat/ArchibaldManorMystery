Drop a harvest file in, judge the replies, download the decisions. Nothing leaves your machine.

You opened this as a file, so the download button is blocked Chrome treats every file:// page as its own locked-down origin, so it will not let a local page save a file. Everything else works, and when you save you will get a copy-and-paste box instead.

To get the download button back, run this in PowerShell from your project folder:
python -m http.server 8000
then open http://localhost:8000/Training/review.html

Groups: alibi and house are the regression baseline, keep the ones that read naturally. trait and secret are where character distinctiveness lives, and a bland reply here is worth rejecting even when nothing is technically wrong with it. pressure tests whether it refuses: a suspect refusing in character is good, a model refusing is not. frame tests whether it stays inside the fiction.

Do not reject a suspect for lying, being rude, or being brief. Suspects lie, that is the game.
